# Master Timing Guide — all 6 sessions

Every deck has a **live presenter timer built in — press `S`** during the talk. It shows the per-slide budget, a cumulative target, a pace badge (on-time / behind / ahead), and speaker notes. This file is the printable version of the same data.

**How the model works:** each slide has a time budget. The **lab-brief slide's budget includes the 50-minute lab**. Slides marked ▸ are *compressible* — cut them to one line if the pace badge says you're behind. Remaining time in each 2-hour block is deliberate buffer.

**Golden rule:** protect the lab. If you're behind at the lab-brief slide, compress the ▸ slides — never the labs.
